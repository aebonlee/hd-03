먼저 내 Supabase를 연결하세요

이 예제는 회원 정보를 저장할 곳이 있어야 동작합니다. Supabase 무료 프로젝트를 만들고 아래 네 단계를 따라 하면 됩니다. 자세한 설명은 리포지토리의 README.md에 있습니다.

  1. 1 supabase.com에서 무료 프로젝트를 만듭니다. 지역은 Northeast Asia (Seoul)을 고르세요.
  2. 2 Project Settings > API에서 Project URL과 publishable key를 복사합니다.
  3. 3 index.html을 열어 위쪽의 SUPABASE_URL과 SUPABASE_PUBLISHABLE_KEY 두 줄에 붙여넣습니다.
  4. 4 SQL Editor에서 supabase/schema.sql 내용을 붙여넣고 실행합니다. 회원 정보를 담을 표와 보안 규칙이 한 번에 만들어집니다.

secret key와 service_role key는 절대 붙여넣지 마세요. 이 파일은 브라우저로 그대로 내려가 누구나 볼 수 있습니다. publishable key는 공개돼도 되도록 만들어진 키라 괜찮습니다. 실제로 남의 데이터를 막아 주는 것은 키가 아니라 4단계에서 켜는 RLS입니다.

Reusable Supabase Membership

가입은 간결하게,
정보는 안전하게.

여러 프로젝트에 반복 적용할 수 있도록 회원가입, 이메일 인증, 로그인, 내 정보 수정 흐름을 하나의 HTML에 담았습니다.

  • ✓ Supabase Auth 이메일 중복 방지
  • ✓ 의심·일회용 이메일 사전 경고
  • ✓ 강화된 비밀번호 규칙과 확인 절차
  • ✓ 이름·전화번호 동의 기반 저장 + RLS
이 템플릿의 서비스명과 SITE_CODE만 변경하면 새 프로젝트에 재사용할 수 있습니다.
관리자 전체 회원 조회는 브라우저용 키가 아닌 별도의 권한 설계가 필요합니다.

회원가입

이메일 인증 후 계정 사용이 가능합니다. 모든 필수 항목을 정확히 입력해 주세요.

실제로 메일을 받을 수 있는 본인 이메일을 입력해 주세요.

  • 10자 이상
  • 영문 대문자 1개 이상
  • 영문 소문자 1개 이상
  • 숫자 1개 이상
  • 특수문자 1개 이상
  • 공백 없음

동일한 비밀번호를 다시 입력해 주세요.

수집 항목: 이름, 이메일, 전화번호 · 이용 목적: 회원 식별 및 서비스 운영 · 보유 기간: 실제 운영 정책에 맞게 수정하세요. 동의를 거부할 수 있으나 회원가입은 제한됩니다.

실제 운영 전 Supabase Dashboard에서 이메일 인증과 Password Security 설정을 확인하세요. 프런트엔드 검증만으로 서버 정책을 대신할 수 없습니다.
